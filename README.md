# ASH — Architecture of Human Sense

ASH is an experimental AI-oriented cinematic system that explores how short generative video fragments can be orchestrated into coherent visual narratives.

## 🧠 Problem

Generative video models often produce very short clips, which limits storytelling and narrative continuity.

Instead of treating this limitation as a constraint, ASH approaches short clips as **modular narrative units**, enabling composition, rhythm control, and visual coherence through orchestration.

---

## 🛠️ Solution

ASH demonstrates a modular cinematic workflow where:
- Short AI-generated video segments are created with cinematic prompts
- Each segment functions as a narrative block
- The blocks are curated and composed into a coherent visual sequence

The system focuses on **orchestration**, not just media generation.

---

## 🤖 Use of Gemini

ASH leverages Gemini-based generative models through Google AI Studio to explore cinematic prompt orchestration.

The project uses structured prompts to guide:
- visual style
- lighting
- mood consistency
- narrative flow across multiple clips
