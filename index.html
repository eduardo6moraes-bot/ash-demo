ASH

Inteligência Visual Cinematográfica orientada por IA — uma demonstração de orquestração visual de vídeos e imagens gerados por modelos generativos num formato modular, escalável e narrativo, projetado para o Hackathon Gemini 3.

Sobre o Projeto

ASH demonstra como limites técnicos — como duração curta de clipes — podem ser transformados em blocos narrativos intencionais. Cada segmento é gerado com prompts cinematográficos e estruturados para criar uma experiência visual coesa e estética.

Principais Características

✔️ Arquitetura modular de vídeos
✔️ Narrativa visual orientada por IA
✔️ Consistência estética e ritmo
✔️ Escalável para composições maiores
✔️ Uso efetivo de modelos generativos para storytelling

Projeto desenvolvido para o Gemini 3 Hackathon.
