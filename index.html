ASH

ASH é um sistema de orquestração visual cinematográfica orientado por IA, projetado para transformar clipes curtos gerados por modelos generativos em narrativas visuais coerentes e escaláveis.

Demonstração em Vídeo

Sobre o Projeto

O projeto explora uma abordagem modular para storytelling visual, onde limitações de duração de vídeo são tratadas como blocos narrativos independentes. Cada fragmento é concebido como parte de uma composição maior, permitindo organização, ritmo e coerência estética orientados por inteligência artificial.
